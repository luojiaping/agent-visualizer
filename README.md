# Agent 运行可视化演示

单文件静态页，演示一次 AI Agent 任务执行中**工具调用的图谱化呈现**：主区域是干净的对话界面，执行过程放在侧边栏，用 DAG 图谱画出来——一次 reasoning 扇出多个并行工具调用、结果扇入、失败分叉重试。节点随运行流式生长，图谱可缩放、拖拽。

## 演示内容

模拟剧本：iOS 登录闪退全链路排查。24 个节点 / 15 次工具调用，含三路并行扇出（搜代码、读文件、统计崩溃）、定位 Token 刷新竞态、并发测试失败标红分叉、修复后重跑通过、最终回复。数据为模拟演示数据。

## 视觉

近黑底 + 香槟金 + 银灰光球，节点为半透明线框球体，触须按工具类型分 pastel 色并带游走脉冲，视觉语言参照 [neural-creator-dashboard](https://github.com/luoluo-121/neural-creator-dashboard)。

## 使用

无构建、无依赖，直接用浏览器打开 `index.html` 即可。
